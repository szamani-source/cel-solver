Case setup reference

Every file and keyword celFoam reads, what it does and its default. A celFoam case is an ordinary OpenFOAM case: a mesh, initial fields, and a few dictionaries. The physics is set in constant/materialProperties.

This page is checked automatically: the manual's test fails if the code reads a keyword that is not described here. Unknown keywords in your files are ignored by celFoam, so a misspelt optional entry silently takes its default. Read the settings block at the top of log.celFoam to confirm what was understood.

system/controlDict

The standard OpenFOAM entries apply (startFrom, startTime, stopAt, endTime, writeFormat, ...). celFoam sets the time step itself every step, so deltaT is only a starting value. Notes on the entries celFoam treats specially, and the entries it adds:

KeywordDefaultMeaning
writeControl, writeInterval–With writeControl adjustableRunTime, celFoam shortens the steps before each write so that the run lands exactly on every multiple of writeInterval and on endTime. Use it: a restart from such a time takes the same steps as the run that wrote it.
maxCo0.4Fraction of the stable explicit time step used (Courant number on the fastest wave). Must be positive. Values up to about 0.4 are tested; see Time step.
gravityRamp0Seconds over which gravity grows from zero to its full value (a half cosine). A ramp of about 0.1 s avoids a shock when a deposit is loaded at once.
damping0Velocity damping rate in 1/s: after each momentum update \(\mathbf v \leftarrow \mathbf v/(1 + c\,\Delta t)\). Used to settle a deposit to rest. Switched off automatically when the first outlet opens. 100 to 250 1/s settles the tutorial silos.
dampingStart0Time from which damping acts. Lets material fall freely while a silo is filled through an inlet, then settle.
solveMomentumyesno holds the velocity field fixed (prescribed motion). Only for kinematic tests of the remap and the stress update.
secondOrderyesno uses first-order face states in the Lagrange step. Only for tests.

constant/materialProperties

General entries

KeywordDefaultMeaning
rhorequiredDensity of the material, kg/m³. Also the default for cells without a 0/rho field.
freeSurfacenoyes: each cell holds material plus void, tracked by the field alpha. Needed for anything with a free surface, outlets, inlets, moving bodies or empty space. no: the mesh is full of material everywhere (a closed box of solid).
typerequiredMaterial model: linearElastic, vonMises, druckerPrager or mohrCoulomb. The same word, inside a material sub-dictionary, selects the model of a deformable body.

Material model parameters

Angles are in degrees, stresses in pascals. Theory: Material models.

ModelRequiredOptional
linearElasticE Young's modulus, nu Poisson's ratio–
vonMises (J2 plasticity)E, nu, sigma_y yield stressH linear hardening modulus (default 0, perfectly plastic)
druckerPragerE, nu, phi friction angle, c cohesion, psi dilation anglefit: how the cone matches Mohr-Coulomb: compression (default, outer cone), extension (inner cone) or plane_strain; the friction, nonlocal and cap entries below
mohrCoulombE, nu, phi, c, psisigmaT tensile strength (tension cut-off, \(0 \le \sigma_T \le c\cot\phi\)); the friction, nonlocal and cap entries below

Drucker-Prager in plane strain and on the wedge. Use fit plane_strain; for silo and hopper flow. The default compression fit gave a third of the discharge rate of the Couto silo (45 against 110 kg/s).

Tension. With freeSurface yes, a material with c 0 or sigmaT 0 carries no tension: it separates instead. A cohesive Mohr-Coulomb or Drucker-Prager material carries tension up to sigmaT (default \(c\cot\phi\)) and tears beyond it.

Rate-dependent friction \(\mu(I)\)

Adding these entries to mohrCoulomb or druckerPrager makes the friction coefficient rise with the inertial number \(I\), from \(\mu_s = \tan\phi\) at rest to mu2 in fast flow Jop et al. 2006. Without mu2 (or with mu2 equal to \(\tan\phi\)) the model is rate independent.

KeywordDefaultMeaning
mu2offFriction coefficient at high \(I\) (must be above \(\tan\phi\))
I0with mu2Reference inertial number (0.279 for glass beads)
dwith mu2Grain diameter, m
rhoSwith mu2Density of the grains, kg/m³
muIAlpha0Barker-Gray regularisation of the law at small \(I\), in (0, 2); 0 = off Barker and Gray 2017
phi0, phiC, bPhi, KDiloffOptional dilatancy: the dilation angle follows the solid fraction, \(\tan\psi = K_\text{dil}(\phi_s - \phi_\text{eq}(I))\) with \(\phi_\text{eq} = \phi_C - b_\phi I\), \(\phi_s = \phi_0\exp(-\operatorname{tr}\boldsymbol\varepsilon^p)\). All four or none. Experimental, off in all tutorials.

Nonlocal friction law (mesh-independent shear bands)

KeywordDefaultMeaning
nonlocalA0 (off)Nonlocal amplitude \(A\) of the granular fluidity law Kamrin and Koval 2012. With it, the plastic flow spreads over a length of a few grain diameters d, so shear bands no longer shrink with the cells. Needs the \(\mu(I)\) entries (mu2, I0, d, rhoS), and flowImpedance yes. \(A = 0.48\) is the glass-bead value Henann and Kamrin 2013. Writes the fluidity field g (1/s).

Compaction cap

KeywordDefaultMeaning
capLambda0 (off)Modified compression index \(\lambda^* = \lambda/(1+e_0)\): loading along the cap follows \(\varepsilon_v = \lambda^*\ln(p/p_0)\). From an oedometer or isotropic compression test. Writes the preconsolidation pressure field pc (Pa). Not yet available together with STL walls or bodies.
capP0100Pressure (Pa) at which material is first taken as normally consolidated: the cap starts at \(\max(p, p_0)\).

Granular flow rules

The cell-face rules below make frictional material flow and stop correctly on a fixed mesh. Their reasoning is in Theory: flow rules. All default to no.

KeywordDefaultWhat it does
shearCapnoCaps the shear stress the Riemann solver passes across a face at the Mohr-Coulomb yield of phi and c; a capped face slips.
normalCapnoCaps the normal stress jump at faces at yield, as shearCap caps the shear jump.
spreadLayersnoA partly filled top cell whose material sits on its lower side spreads sideways along the surface. Needs freeSurface yes.
flowImpedancenoBetween flowing cells the face uses the viscosity of the \(\mu(I)\) law instead of the elastic shear impedance, so the flow resistance no longer depends on \(E\). Needs mohrCoulomb or druckerPrager with mu2.
fullBlendnoCells that are nearly full blend smoothly between the full-cell and the partly filled rules instead of switching. Removes speed spikes in partly filled cells; recommended for silo and hopper discharge and with capLambda.
fullBlendVoid(1e-4 1e-2)Range of the void fraction over which fullBlend blends.
overfillStressnoyes: a cell the remap overfills (more material volume than the cell) takes the excess as an elastic volume strain, so its stress pushes the excess back out. no: the excess mass stays in the cell with no stress, so the packing can densify in a long fast flow. Used by the fluidised dam break (WP F.8c, decision 0133).
princetonFr0 (off)Pa. Packing-dependent frictional pressure (Princeton law, as Breard et al. 2019; WP F.8f, decision 0133): the effective mean stress of a cell is kept at or below Pc = Fr (εs − εmin)r / (εmax − εs)s, εs = rho/(alpha rhoS) the solid fraction (0 below εmin). A loose packing carries little stress and compacts under load; a dilating flow loses its friction. Needs rhoS. Breard: 0.05
princetonR, princetonS2, 5exponents r and s of the Princeton law
princetonMin, princetonMax0.49, 0.64solid fractions εmin (no frictional stress below) and εmax (random close packing)
voidPlasticFlownoIn a partly filled cell, plastic expansion of the material goes into the cell's void instead of compressing the material. Lets surface cells of a dilatant material dilate.
restRelaxoffSub-dictionary { time T; speed v; K0 k; }: in full cells slower than speed (m/s), the horizontal stress relaxes towards K0 times the vertical stress with time constant time (s). Removes sideways stress locked in when a silo is filled from the top. K0 defaults to \(1-\sin\phi\) Jaky 1944. Needs gravity. Example: restRelax { time 0.05; speed 0.01; }.
remapLimiterssee rightSub-dictionary choosing the slope limiter of each field in the remap: { rho MC; U MC; sigma MC; epsP superbee; epsPEq superbee; } (these are the defaults). Choices: upwind, minmod, MC, superbee.

Walls: walls

One entry per mesh patch that is a rigid wall:

walls
{
    left       { friction 20; }   // wall friction angle, degrees, 0 to below 90
    hopperWall { friction 11.3; }
    top        { friction 0; }    // smooth lid
}

A wall stops the normal velocity, carries no tension (material separates from it) and resists sliding with a Coulomb shear stress of at most \(\tan\delta\) times the wall pressure, where \(\delta\) is friction. The patch must exist in the mesh.

Outlets: outlets

outlets
{
    outlet { friction 20; openTime 0.3; }
}

An outlet patch is a closed wall with friction friction until the first step at or after openTime (s; default: never), then a free outflow face: material that crosses it leaves the domain and is added to the discharged mass in the log. Opening the first outlet switches the damping off. Needs freeSurface yes. The patch must be a plain patch without a fixed velocity, and not also listed in walls.

Inlets: inlets

inlets
{
    inlet
    {
        speed       0.6;      // m/s into the domain, normal to the patch (Function1 of time)
        startTime   0.3;      // s, default 0
        endTime     2.0;      // s, default never
        density     1800;     // kg/m^3 of the fed material, default rho
        pressure    0;        // Pa, initial pressure of the fed material, default 0
        friction    0;        // degrees, wall friction while closed, default 0
    }
}

Between startTime and endTime the patch feeds fresh material into the domain at speed; outside that time it is a closed wall. The fed mass is printed in the log. speed is an OpenFOAM Function1, so it can be a constant, a table, a sine, and so on. Needs freeSurface yes; the patch must be a plain patch, not also a wall or an outlet.

Surface loads: loads

loads
{
    top { pressure 2000; startTime 0; }   // Pa on the patch from startTime (s, default 0)
}

A uniform pressure on a plain patch from startTime on (version 2, decision 0128), for example the load of a consolidation test.

constant/gasProperties (version 2, in development)

Optional. Without this file, or with model none, the solver behaves as version 1. With it, air in the pores and the void is solved together with the grains (decisions 0125 to 0132). All tests use the ergunWenYu drag law.

model       poreGas;    // none | poreGas | gasFlow (gas velocity in the void, needs freeSurface)
rhoP        2650;       // grain (particle) density, kg/m^3
d           0.0001;     // grain diameter, m
T           293.15;     // gas temperature, K (default)
p0          101325;     // ambient pressure, Pa (default)
drag        ergunWenYu; // ergunWenYu (default) | ergun | wenYu | diFelice | syamlalOBrien | beetstra
coupled     yes;        // gas pressure acts on the grains, grains carry the gas (default)
alphaVoid   1e-4;       // cells below this alpha are void for the gas (default)
inflow      { bottom 0.05; }   // fixedGradient patches of 0/p blowing gas in, m/s at p0;
                               // a Function1 of time, e.g. bottom table ((0 0) (0.3 0.05));
nOuter      50;         // Newton iterations per step, at most (default)
nAnderson   5;          // Anderson acceleration depth (default)
pTolerance  1e-9;       // Pa, converged when the correction is below this (default 1e-14 p0)
laplacian   "Gauss linear corrected";
solver      { solver PCG; preconditioner DIC; relTol 1e-3; }   // pressure corrections
nCorr       1;          // gasFlow: pressure corrections per step (default)
divUg       "Gauss upwind";   // gasFlow: convection of the gas velocity (default)
USolver     { solver PBiCGStab; preconditioner DILU; relTol 1e-10; }   // gasFlow momentum
poreInertia yes;        // gasFlow: gas momentum in the pores as well as the void (default)
inertiaForce no;        // gasFlow: pore gas inertia's reaction on the grains (default off, decision 0132)
surfaceCarry no;        // free surface: yes lets the moving surface carry gas to and from the void
                        // (the vacated part of a cell fills from the void, not through the grains; decision 0133)
eMin        0.2;        // smallest gas fraction of the filled part of a cell (remap overfill; decision 0133)
diffusivity 0;          // poreGas only, m2/s: > 0 replaces gas compressibility by a pore pressure that is
                        // carried with the grains and diffuses with this coefficient (Gueugneau 2017,
                        // Aravena 2021); fitted, e.g. 0.015 for the Roche dam break (default 0 = off)
frictionOnly no;        // with diffusivity: yes = the pore pressure only lowers the grains' friction
                        // (internal and wall) as in Gueugneau 2017 and Aravena 2021: sigma stays the
                        // total stress and the constitutive update sees sigma + min(p, P) I; no gas
                        // force acts. Start sigma as the total stress (decision 0133, WP F.8g)

The gauge gas pressure is the field 0/p (optional): fixedValue patches are open at that pressure, zeroGradient patches are sealed. Outlets must be fixedValue. With model gasFlow the field 0/Ug (optional) is the gas velocity; without it walls are no-slip and open patches zeroGradient. Written: p, phiS, phiG, k, qGas and, with gasFlow, Ug.

Initial fields

celFoam reads these fields from the start time folder if they are there, and otherwise creates them with the default:

FieldDefaultNotes
alpha1material volume fraction (with freeSurface yes); 0 in empty cells
rhorho of materialPropertieswith freeSurface yes the bulk density, cell mass over cell volume: set it to 0 where alpha is 0
U0m/s; a fixedValue patch here prescribes the boundary velocity
sigma0Pa, positive in tension; the material usually starts stress-free and gravity loads it
epsP, epsPEq0plastic strain and equivalent plastic strain
pc0preconsolidation pressure of the cap (0 = not loaded yet)

The usual way to place material is setFields with boxes, cylinders or surfaces, as in the quick start: set alpha 1 and rho to the density inside, alpha 0 and rho 0 outside.

Starting at rest

Two ways to get a deposit at rest before anything moves:

  • Gravity on (default, recommended): place the material stress-free, ramp gravity in (gravityRamp 0.1), damp the motion (damping 100 to 250) and keep the outlet closed until it settles (openTime, typically 0.3 s for a small tank, about 1 s for a 2 m silo). This gave the best wall pressures for the Couto silo (Janssen coefficient \(K = 0.43\)).
  • Filling from the top through an inlet, as in reality, with dampingStart after the fill and restRelax. Impacts lock sideways stress into the deposit; restRelax removes it, but upper wall pressures still come out high (decisions 0108, 0114).

Lagrangian bodies and STL walls: constant/rigidBodies

Every body is an entry in bodies. Its surface is a closed triangulated surface (STL, OBJ, ...) in constant/triSurface, given in its position at time zero, with outward normals.

bodies
{
    leftWall                         // a fixed wall: no velocity, no mass
    {
        surface     leftWall.stl;
        friction    20;              // wall friction angle, degrees, default 0
        adhesion    0;               // wall shear strength at zero pressure, Pa, default 0
    }
    pile                             // prescribed motion
    {
        surface     pile.stl;
        centre      (0.2 0.5 0.005); // reference point, default the surface centroid
        velocity    constant (0 -0.1 0);   // Function1, m/s
        omega       constant (0 0 0);      // Function1, rad/s
    }
    block                            // free body: moved by the material and gravity
    {
        surface     block.stl;
        mass        0.75;            // kg (2D: of the one-cell-deep slice)
        inertia     (1e-3 0 0 1e-3 0 1e-3);  // kg m^2 about the centre; without it no rotation
        velocity    (0 0 0);         // initial velocity
    }
}
KeywordDefaultMeaning
surfacerequired (unless deformable)file in constant/triSurface
centrearea-weighted centroidpoint that velocity moves and omega rotates about
velocityzeroprescribed velocity of the centre (a Function1 of time: constant, table, sine, ...); initial velocity (a plain vector) for a free body
omegazeroangular velocity, rad/s, the same way
friction0friction angle between the material and the body, degrees
adhesion0shear strength of the contact at zero pressure, Pa (a rough wall in clay: the undrained strength)
mass0 (not free)makes the body free: its motion follows from the material's force and gravity
inertianonerotational inertia of a free body (symmetric tensor (xx xy xz yy yz zz))
deformablenonea deformable body instead of a rigid surface (below)

A body without velocity, omega and mass is a fixed wall. Fixed bodies give walls of any shape on a mesh that does not follow them: the cells they cut keep only their open part. The force of the material on every body is written every step to postProcessing/bodyForces.dat, and each body's motion to postProcessing/rigidBodies/<body>.dat. The utility celBodyCells shows which cells the bodies cover (fields alphaBody, bodyFaceOpen) without running the physics.

Deformable bodies

footing
{
    deformable
    {
        min         (0.1 0.15 -0.01);     // box of hex8 elements, m
        max         (0.2 0.25 0.02);
        cells       (10 10 1);            // elements along x, y, z
        density     7800;                 // kg/m^3
        material    { type linearElastic; E 2e11; nu 0.3; }
        planeStrain yes;                  // no z motion (2D runs), default no
        hourglass   0.05;                 // hourglass stiffness, default 0.05
        hourglassType stiffness;          // stiffness (default) or viscous
        damping     0;                    // element damping, default 0
        drive       (0.09 0.24 -1) (0.21 0.26 1);   // nodes in this box follow velocity
    }
    velocity    constant (0 -0.25 0);     // of the driven nodes
    friction    20;
}

densityrequiredkg/m³

planeStrainnono velocity along z (one element thick, 2D runs)

Keep the elements close to the Eulerian cell size; much finer bodies pack the material under them (decision 0073).

Axisymmetric wedge

Round silos, hoppers and bars are run as a thin wedge: a slice of a few degrees about the axis, one cell thick, with its two sides of type wedge and the degenerate faces on the axis of type empty. celFoam detects the wedge from the patch types and adds the hoop terms; nothing else is set. The wedge is built with blockMesh (see Meshing); the tested half angle is 2.5°. Masses and forces in the log are those of the wedge slice: multiply by \(360/(2\theta)\) for the full body (\(2\theta\) the wedge angle).

Parallel runs

decomposePar
mpirun -np 4 celFoam -parallel
reconstructPar

A standard system/decomposeParDict works; the tutorials use simple or scotch. Bodies, STL walls, outlets, inlets, the wedge and restart all work in parallel. Results agree with serial to round-off until a threshold in the flow rules switches differently on the two runs; after that the runs part like two serial runs with a tiny perturbation (decision 0080).

Restart

To continue a run, set startFrom latestTime; and a later endTime in system/controlDict, and run celFoam again (on the processor folders for a parallel run). Besides the fields, celFoam writes the state it needs to restart in <time>/uniform/eulerianSolid and, with bodies, <time>/uniform/rigidBodies. The restarted run matches the continuous one bit for bit with writeFormat binary; (or writePrecision 17;). A free body cannot restart yet.
