# celFoam 1.1.0

Adds the case setup tools to version 1.0.0. Nothing in the solver changed: cases written
for 1.0.0 run unchanged and give the same results. GPL-3.0.

**Install or update:** as for 1.0.0 (`INSTALL.md`, `./install.sh`). Then `celfoam test`.

## What is new

- **`celfoam setup`** (celSetup) writes a complete, runnable case: mesh, every
  dictionary, the material at the start and an Allrun that resumes.
  - From a short YAML input file (`celfoam setup my.yaml myCase`), or from a setup page
    in your browser (`celfoam setup --gui`), served on your own computer only, offline.
  - Templates: `conicalHopper` (a cylinder on a conical hopper, axisymmetric wedge or
    plane), `flatBottom` (a flat-bottomed silo, or a plane tank with a small bottom
    opening) and `userMesh`.
  - Meshing with blockMesh (default, the validated Couto mesh exactly) or Gmsh (open
    source, the same block layout; decision 0120). The page can mesh with both and
    compare them.
  - Your own mesh (decision 0121): an OpenFOAM case or polyMesh folder, or `.msh`, `.geo`,
    `.unv`, `.neu`, `.ans`, scaled; pick a condition for each boundary patch (wall,
    outlet, inlet, symmetry, wedge, empty, free). 2D and axisymmetric wedge meshes.
- **`celfoam check`** (celCheck): the time step exactly as celFoam computes it and the
  cell that sets it, outlet cells in grain diameters (about 1 d or less), cells across
  the wall shear band, non-orthogonality, size jumps and a run-time estimate.
- **Manual:** new page "Setup tool"; tutorial `setupPlaneTank`.

## Known limitations

As for 1.0.0 (`docs/release-notes/v1.0.0.md`), and:

1. User meshes: 2D and wedge only; 3D meshes are refused with a message.
2. The faster-time-step mesh options (`outletColumns: even`, `axisColumn`) are off by
   default and not validated against the wall pressures or the discharge (decision 0122).
3. Not in this version: gas in the void and fluid coupling (version 2), temperature,
   Johnson-Cook.
